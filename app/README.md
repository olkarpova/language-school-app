# LearnLingo

Вебзастосунок мовної школи для пошуку викладачів іноземних мов онлайн. Користувачі можуть
переглядати викладачів, фільтрувати їх за мовою, рівнем та ціною, додавати улюблених до обраного та
бронювати пробні заняття.

## Живий застосунок

[https://language-school-app-lake.vercel.app/](https://language-school-app-lake.vercel.app/)

## Функціонал

- **Авторизація** — реєстрація, вхід та вихід через Firebase Authentication
- **Список викладачів** — дані завантажуються з Firebase Realtime Database
- **Фільтрація** — за мовою викладання, рівнем знань та ціною за годину
- **Пагінація** — завантаження карток порціями через кнопку "Load more"
- **Детальна інформація** — розгортання картки з досвідом та відгуками ("Read more")
- **Обране** — додавання викладачів до улюблених (лише для авторизованих), зі збереженням у
  localStorage
- **Приватна сторінка Favorites** — перегляд збережених викладачів
- **Бронювання пробного заняття** — модальне вікно з формою

## Технології

- **Next.js** (App Router)
- **React** + **TypeScript**
- **Firebase** — Authentication та Realtime Database
- **react-hook-form** + **yup** — робота з формами та валідація
- **CSS Modules** — стилізація
- **localStorage** — збереження списку обраних

## Сторінки

- `/` — головна
- `/teachers` — список викладачів із фільтрами
- `/favorites` — обрані викладачі (приватна, лише для авторизованих)
